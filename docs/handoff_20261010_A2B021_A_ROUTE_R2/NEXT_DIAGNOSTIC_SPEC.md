# 下一项输入诊断建议规格

账户 A，供用户转交 B 评估。沿用 A2B-021 路线补充；本文件不增加真实训练授权。

目的：用一次有限、无模型拟合的诊断，判断当前输入是否存在稳定、可在训练折内处理的缺陷，再决定是否值得申请一个新配对实验。不要先建候选再寻找解释。

数据边界：仍为当前 81 口完整窗口井和冻结的 325 项输入，使用既定锚点前完整月信息。当前特征与行顺序仅作诊断对象，不重定义事件或标签。禁止使用测试标签、测试分布来挑选特征或规则，不使用第三方数据。

实施范围：

1. 先核对 325 项列的预期含义。区分井级静态描述、预测期索引及随预测期变化的列。同一井重复出现 12 行，不得直接当成 12 个独立样本计算井间信息量；只有确认井内恒定的列，才按一井一份摘要统计。
2. 沿用既有六组切分，所有统计规则只在每个外层训练折定义。统计全缺失、常量、近常量、有效独立井数和缺失模式；近常量阈值事先写定。输出跨折数量范围或分布，不输出特征真实值、井号或可定位单井的摘要。
3. 重复/相关诊断先按安全的特征家族归组。精确重复要区分缺失模式与观测值；数值相关只使用训练折共同有效井，锁定最小共同样本数与阈值，并同时记录有效井数。相关性只作为冗余证据，不自动删列。
4. 尺度回退只依据未经填补的原始尺度状态；分开记录非有限、非正等技术原因，不能把零值解释成停井，也不能将 `scale==1` 当作回退标记。小组及补集均需通过既有隐私阈值。
5. 只引用已有 OOF 匿名误差预算，不重建 OOF，不用验证标签计算特征优劣或决定保留列。任何涉及真实模型、预处理、编码器、筛选器拟合的动作均超出本诊断。

交付应限于：诊断规格与源码身份、匿名跨折统计、信息边界检查、机制判断和后续决策。至少明确列出哪些发现可以重复、哪些只是统计现象、哪一个改动可检验该机制。

停止与决策：

- 存在稳定且可处理的问题：提出一个主要机制、一个同边界对照和至多两个固定候选；完整锁定候选与次数预算后再进入训练授权。
- 没有稳定问题：交付“未找到支持特征简化的证据”，结束该支线，不强行生成删列模型。
- 发现时间边界或特征含义不确定：按影响范围隔离，完成其余检查；不自行改变官方目标和窗口。

本诊断不要求再次重跑 A2B-021，也不要求重复测试与本任务无关的旧门禁。后续如果特征集合改变，需为候选设定独立的特征身份；不能篡改冻结基线的 325 项检查来让候选通过。
