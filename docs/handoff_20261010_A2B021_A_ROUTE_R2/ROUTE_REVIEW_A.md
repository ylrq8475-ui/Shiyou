## 路线存在的五个问题

### 1. 收尾正在占用“下一轮研究”的位置

最近一次是接收回函，没有新的模型信息。继续互相确认同一份结论，只会增加交接轮次。A2B-021 的收尾核对到此可以结束；只有新增实现、证据冲突或候选结果才值得再次复测。必要的冻结和隐私检查应保留，次数不应被当作研究进展。

### 2. 损失最多的组，不一定最值得优先修复

上一轮 A 提醒“普通正尺度组贡献约 60.74%，不能只盯低产组”仍成立，但它不足以将普通组列为异常或优先提分对象。本次补上井数分母：

|预测前状态组|五组重复平均井数|井数占比|损失占比|损失占比减井数占比|
|---|---:|---:|---:|---:|
|原始尺度回退|14|17.28%|20.23%|+2.95 个百分点|
|训练折正尺度 q25 低组|17|20.99%|19.03%|-1.96 个百分点|
|其余正尺度组|50|61.73%|60.74%|-0.99 个百分点|

普通组的损失总量主要与井数规模相当；低尺度组也没有表现为最大的人均损失来源。尺度回退组有较高的相对负担，但其可修复部分仍未知。该表来自既有五组重复的平均构成，并不代表 405 口独立井；低尺度分组由各训练折分位数确定，成员和数量可随切分变化。

后续优先级应同时考虑损失规模、预测时可识别性、异常机制证据与预计可修复部分。不能按总损失排序就自动建立分组模型，也不能用真实高损失成员作预测路由。

### 3. 同批 OOF 已承担过多次选择

多轮实验已经查看这 81 口井上的固定五折和重复切分。分组正确可避免同井同时进入训练和验证，但不能消除反复挑选算法带来的选择偏差。换随机种子也没有增加独立井。

新的种子可检查划分敏感性；保留确认的价值取决于方案在查看该成绩前是否真正冻结。即使确认成绩此前未看过，它仍来自已经参与研究的这批井，不能称为独立新测试集。后续若在候选内部选择参数，必须在外层训练井中完成；历史研究已经造成的信息使用无法靠重新切分完全消除。

当前没有增益的结果仍是有效负证据，不能反过来归咎于验证规则过严。但“未达 +0.20”只表示未达到既定最小收益要求，不等于统计上证明无效。旧轮次门槛不能事后放宽；未来规则如需调整，应在新成绩产生前说明最小实际收益和不确定性如何共同判断。

### 4. 结构统计还没有成为可修复机制

325 项特征、81 口独立井、B0 叶节点训练井支持偏少，均提示需要诊断，但都不足以单独证明过拟合。C1 的独立井支持均值从约 1.85 增至 3.94，却没有稳定增分，已经削弱了“支持不足就是主因”的简单解释。

只训练前两月还会减少后续月份提供的共享结构信息，并改变每井训练行数、有效叶支持和预处理样本分布。因此 C1 的结果应解释为整个早期专用方案的效果，不能单独归因于月间干扰。继续照搬“拆月份→换更复杂模型”的固定顺序，证据不足。

特征冗余也应谨慎解释：高度相关的列不一定无用；低方差不等于没有预测价值。删除相关列会改变随机树抽取候选特征的实际组成，即便 `max_features` 比例相同，也不能把全部分数变化解释为噪声减少。

### 5. 审计假设不能变成已确认事实

B 收尾 README 写有“官方不会补充事件时点的既有事实”。本次交付没有附相应官方或用户确认来源，A 目前能够确认的是“尚未获得明确解释”。如果该表述来自另一个会话的用户说明，应标为用户反馈并给出可追溯位置；不能提升为官方事实。这不影响 A2B-021 的分数或停止决定，也不应使研究无限等待回复。

## 调整后的下一步

将下一项工作限定为训练输入有效性诊断，见 `NEXT_DIAGNOSTIC_SPEC.md`。它应回答“是否存在可在训练折内稳定识别的信息缺陷”，而非泛泛计算更多统计。

如果发现稳定的近重复或结构性缺失问题，可设计一个固定规则的特征简化配对实验。若诊断没有异常，就停止这条支线，不能为了把流程走完而删列。模型实验保留全 12 月共享对照，先限制在一个主要改动；任何新候选、参数或融合都需有自己的分数前锁定与用户授权。

当前暂不优先扩大早期模型网格、搜索融合权重或启动深度学习。并非证明这些方法无法提分，而是现有证据尚未给出比输入有效性更明确的假设。A 也不会保证一次特征诊断就能定位最大误差源。
