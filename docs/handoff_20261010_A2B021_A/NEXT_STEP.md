# 下一步建议

账户 A 独立审计与交付。本文件是研究建议，不是新增训练授权。

## 先完成本轮收尾

B 接收回函后，在既有授权范围内记录 A2B-021 复核完成、六方案未过门槛、无升级候选。保留失败结果，维持原模型和正式包；不要补跑旧 A2B-020，也不要动用未使用的确认成绩。

## 下一轮应改换研究问题

本轮最接近基线的 C1 仍切分敏感；换成当前两种 HGB 或固定融合没有带来收益。继续增加同类模型数量会增加同批 OOF 选择偏差。现有汇总也不能确定最大可修复机制。

优先建议：先做不拟合的训练输入有效性诊断，再决定是否值得进行一个小型配对实验。核对当前 325 项特征在训练折内的有效独立信息量，包括近常量、缺失状态、短中长统计的高度冗余，以及不同训练井实际可区分程度。报告只能发布匿名组级信息，相关阈值与组别应在查看新候选成绩前锁定。不得按验证标签挑选特征；拟合型筛选必须仅在训练折执行。

这个方向检验的是“高维冗余与有限独立井样本是否使当前模型对跨井差异拟合不稳”。它仍是假设。不能仅凭 81 井与 325 特征的数量，或叶节点支持低，就认定已经发现过拟合原因。若诊断没有可重复的异常，不因急于提分直接启动删特征或调参。

若后续获得用户实验授权，应将“折内固定规则特征简化”和“井级支持正则化”分别设置同边界对照，不同时改目标、尺度、切分与特征。先以完整 12 月共享模型为参照，限制候选数，确认月份损失和三个预测前状态组是否受损。原始尺度回退组不能当作低产组的替代定义。普通正尺度组贡献约 60.74% 总损失，应保留为主检查组。

此前多个轮次已看过这些固定折和重复切分，因此它们属于研究验证，不再等同于未见数据。下一轮门槛、候选、次数预算、保留确认及停止条件必须分数前锁定；不能以新增随机种子声称获得新的独立样本，也不能用榜单反复挑超参数。

## 暂不建议的操作

- 放宽 A2B-021 门槛、只取 C1 正向种子或搜索融合权重。
- 因 C3 优于 C2 就替换现有 ExtraTrees。
- 按真实零产、真实快速下降、高损失井分型训练或路由。
- 把本轮失败解释成“树模型已到上限”或直接启动深度学习大搜索。
- 以榜单高分关闭事件语义或预测时点 P0。

当前没有证据保证下一轮增分或达到 90。最需要的是一个经同边界配对验证的机制，而不是更多候选名称。
