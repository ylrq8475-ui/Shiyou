# 95+ 方向评估：研究路线审查

署名：**独立方案研究账户：95+方向评估**。2026-10-13，Asia/Shanghai。本账户不替代账户B的训练职责，也不替代账户A2的审核职责；本文不是 A2 审核通过，也不是 B 执行记录。本轮没有任何真实拟合。

## 结论先行

1. **目前没有任何一条路线有可信的 95 路径。** 这不等于 95 已被证明不可能。按现有证据，任何单一机制都覆盖不了 95 所需的误差预算。
2. 瓶颈不是单一的，而是**井级产量水平误差与逐月形状误差大致各占一半**，两者近似独立相加（见第二节）。只修其中一个，按比例外推到平台也到不了 95。
3. **首选路线 A：锚点月信息锚定。** 这是目前唯一已识别、当前模型完全没用到、并且能改变全部 10 口测试井 B0 预测的信息来源。它针对水平误差，但先要通过一个零拟合信息量检验才值得训练。
4. **备选路线 B：停产月感知的两段式预测。** 官方指标对真值为 0 的月份是“全有或全无”，B0 结构上几乎不会输出 0。这一机制的大小目前未知，先用零拟合计数测定。
5. **暂缓路线 C：A2 提出的 ExtraTrees absolute_error 单因素。** 它与官方指标在对数空间有合理的一致性，但作用于叶内估计，量级上不可能覆盖 64% 的损失，且有相近的负先验（A2B-021 C3）。可作为低成本诊断，不作为 95 路线。
6. **最先应该花的资源是零拟合诊断（D1–D4）**，不是新的训练。它们用很低的成本回答三个决定性问题：
   - M 月里到底有没有水平信息；
   - 停产月占多少损失；
   - 就算完美预测平滑曲线，在这批井上能到多少分。

## 二、误差几何：为什么说“各占一半”

官方单月损失可以精确改写为 `|p−y|/(p+y) = tanh(|ln(p/y)|/2)`（忽略 1e-6；合成核对误差 8.7e-7）。如果把每月的对数误差近似看成同分布 N(0, σ²)，每个分数都对应一个等效对数误差尺度 σ（`synthetic/LOSS_GEOMETRY.json`）：

| 状态 | 分数 | 等效 σ |
|---|---:|---:|
| 当前 B0 OOF | 73.71 | 0.710 |
| 只剩形状误差（水平完美） | 80.94 | 0.497 |
| 只剩水平误差（形状完美） | 81.22 | 0.490 |
| 平台 86.2003 | 86.20 | 0.354 |
| 目标 95 | 95.00 | 0.126 |

检验：√(0.497² + 0.490²) = 0.698，与 0.710 只差 1.8%。所以“水平误差与形状误差独立相加”是一个可用的量级模型。

它的含义很直接：
- 在 OOF 上，即使水平完全正确，形状误差 σ≈0.50 也只给 80.9 分；
- 要到 95，水平和形状两部分的残余 σ 都必须降到约 0.09 以下（例如 σ_水平=0.08 时，σ_形状 ≤ 0.097）；
- 平台上则需要把总 σ 从 0.354 降到 0.126，也就是减少 64%。

这是一个高斯近似，不是定理；真实误差有重尾和零值。但它足以说明：**单一机制达不到 95。**

## 三、瓶颈判断（对任务第三节问题 1、2 的回答）

| 候选瓶颈 | 判断 | 依据 |
|---|---|---|
| 预测前信息不足（水平） | **主要瓶颈之一** | 水平神谕 +7.2；每井最优倍数 +14.5。所有模型侧变体都在 ±1 分内，说明在现有输入下水平已基本饱和 |
| 形状 / 逐月波动 | **主要瓶颈之一，可修复程度未知** | 形状神谕 +7.5。其中多少是可预测结构、多少是不可约的月度噪声（停产、作业、计量），现有材料无法区分。这是 D4 要回答的问题 |
| 目标尺度 / 损失与指标不匹配 | 次要 | 对数比目标与官方指标在小误差下一致；A2B-023（绝对 log 目标）−0.97。路线 C 属此类 |
| 停产 / 零值月 | **可能被低估的机制，大小未知** | 官方指标对零值月是全有或全无；B0 几乎从不输出 0。训练数据中确有非正产量（M−1 回退 14 口；M 月非正 6 口），但目标窗口内的零月占比未测 |

**哪些瓶颈可能修复足够大的损失？** 只有“新增水平信息”和“可预测的形状 / 停产结构”两项，在量级上与 95 所需的预算相当。其余各项的历史与机制都指向零点几分级别。

## 四、三条路线

### 路线 A（首选）：锚点月信息锚定

| 问题 | 回答 |
|---|---|
| 1 修复的机制 | 井级水平误差。现在的尺度和特征都截止在措施前的 M−1，而事后产量水平主要取决于措施效果，M−1 无法提供。M 是最后一个事件月，它的 RCYL 可能直接含有措施后的产量水平 |
| 2 证据程度 | 支持：水平神谕 +7.2、最优倍数 +14.5，说明水平信息价值很大；测试井 10/10 在 M 月有正产量；v7（含锚点月 + 层位）OOF 76.41，比 A013 高 2.70，是历史上最大的 OOF 增量。反证：v7 平台 80.54，比 A013 低 5.66。但 v7 与层位等因素混杂，且平台只有 10 口井，抽样宽度约 ±6 分。**仍是假设**：M 月是否含措施后产量、在真实预测时点是否可得、是否是半月或停机月 |
| 3 覆盖范围 | 改变所有 M>0 井的全部 12 个月：测试 10/10、训练 75/81。水平误差在前两月权重最大 |
| 4 潜力为何更大 | 它增加的是**信息**，不是对同一信息的不同拟合。所有已失败的变体都在同一信息集内 |
| 5 与旧实验的区别 | A2B-019 比较的是更保守的截止（段首前一月），方向相反；v7 同时引入层位和其他配置，从未做过“只把截止从 M−1 改到 M、不含层位”的单因素。A2B-023 改的是目标变换，不是信息 |
| 6 复杂度与 81 井 | 不增加模型复杂度：同 325 列生成器、同 ExtraTrees、同目标定义，只移动截止 |
| 7 防泄漏与选择偏差 | M 不在目标窗口 M+1..M+12 内；测试输入本身包含 M 记录，所以对平台不构成未来信息。需改写截止不变性审计（删去 ≥M+1 的记录，特征不得变化）。先用零拟合 D2 判断是否值得训练；训练阶段先固定后看确认，确认种子新用；平台分数不参与任何选择 |
| 8 最小同边界对照 | B0（截止 M−1）对 A（截止 M），其余全部相同，配对同折 |
| 9 否定条件 | D2：用 M 作锚的留一井持平预测，在两个锚点都 >0 的井上，分数不高于用 M−1 作锚，或前两月损失不降 → 直接淘汰。训练阶段：未达预注册门槛即否定 |
| 10 预算 | D2 零拟合。训练阶段 70 次 ET 拟合（B0 与 A 各 35 次），按 B 记录每次约 0.4 秒；内存 < 1 GB；依赖与 A24 锁相同 |
| 11 只有小增益时 | 只有小增益说明 M 月信息有限；停止该方向，不扩参数网格 |
| 12 升级为“较可信 95 路径”的证据 | 未见确认切分上，A 的 OOF 达到约 90.5（平台 95 按损失同比例换算的 OOF 等价值）附近；同时 D4 显示平滑上限足够高。只有两者同时成立，才算有 95 路径的证据；单靠路线 A 按第二节的几何不足以到 95 |

### 路线 B（备选）：停产月感知的两段式预测

| 问题 | 回答 |
|---|---|
| 1 修复的机制 | 指标几何。真值为 0 时，任何 ≥1e-3 的预测损失都接近 1；只有精确输出 0 才是 0。B0 输出 expm1(z)·s，几乎从不为 0 |
| 2 证据程度 | 理论确定（`synthetic/ZERO_DECISION.json`）；数据中存在非正产量；A2B-021 曾按“真实零产”做过回顾性切片，但从未建模。**未知**：目标窗口零月占比、是否可由预测前信息识别 |
| 3 覆盖范围 | 只覆盖有停产风险的井月。测试井是否有零月未知；若测试井没有，这条路线对平台无益 |
| 4 潜力为何更大 | 每个被正确识别的零月直接回收该月全部权重；若零月均匀占比 5%，上限约 5 分 |
| 5 与旧实验的区别 | 旧实验都是连续值回归的变体，没有一个改变“能否输出 0”的结构 |
| 6 复杂度 | 增加一个折内分类器 P(y=0) 和一个由公式推出的阈值（约 0.43–0.47，见合成推导），不需要搜索阈值 |
| 7 防泄漏与选择偏差 | 分类器与概率校准都在训练折内；阈值由公式和折内的 ℓ+ 决定，不在全体 OOF 上调 |
| 8 最小同边界对照 | B0 对“B0 + 零判别”，正值月预测逐值不变 |
| 9 否定条件 | D1 中完美零识别上界 < 1.0 分则淘汰；训练后若识别收益没有明显超过误判成本，也否定 |
| 10 预算 | D1 零拟合；训练阶段约 35 次分类器拟合，加复用的 B0 |
| 11 只有小增益时 | 零月少则停止 |
| 12 升级为 95 路径的证据 | 单独不可能；只作为组合中的一项 |

### 路线 C（暂缓）：ExtraTrees absolute_error 单因素（A2 方案）

机制上，对数比空间的中位数与官方指标在小误差下一致；官方指标是有界的（tanh 饱和），对大误差的稳健性甚至强于 MAE。所以它是有道理的诊断。

但它只改变叶内估计，不增加信息，也不改变“不会输出 0”的结构；量级上覆盖不了 64%。A2B-021 C3（HGB + absolute_error，仅前两月）−1.66、0/5 正向，虽然与此不等价，但是相近的负先验。

**判断：** 不作为 95 路线。如果用户希望保留，可在路线 A 的阶段 1 之后作为第三臂单独登记，不与 A 同批选模。
