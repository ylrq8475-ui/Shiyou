## P1：误差预算没有使用官方损失

位置：匿名源码包`source/error_budget.py::weights`第6行。

当前实现：

```python
abs(pred-y) / (abs(y)+1e-6) * 2**(-t)
```

R14要求分解的官方损失是：

```python
abs(pred-y) / (abs(pred)+abs(y)+1e-6) * 2**(-t)
```

独立执行该原函数的合成案例得到预算总损失0.9997555665498374，官方总损失0.3332519205888594。两者约差3倍，案例全部为合成值。目标为0且预测为正时，当前实现还会被epsilon分母放大，足以把低产/零值组错误地判断成主要误差源。

受影响的是月度占比、高估/低估损失贡献、各预测前分组、最差10%井集中度，以及依赖这些报表的误差归因。相关系数使用原始有符号误差，等权融合分数调用原`old.summary`；这两项并不因该分母错误自动失效。正式评分`base/core.py::summary`及冻结官方指标仍正确，且本批没有真实H/T分数。因此按P1诊断实现缺陷处理，没有把它误报成既有平台评分公式已错的P0。

最小修复：补回`abs(pred)`，校验输入有限非负，并在每次预算输出前断言`total_weighted_loss == 1-official_score/100`（容差1e-12）。只检查分桶相加等于自身总量，会让这个错误持续通过；B原50项恰好没有独立的官方损失交叉核对。

编号：**A035-R14-01 / P1 / 未关闭**。影响所有将来误差预算，不要求重新训练未发生的候选。

## P1：少于5井的组可被补集反推

位置：`source/error_budget.py::budget`的小组发布循环。

代码隐藏小组的数值，但仍发布全体井数、全体总损失，以及大组井数和平均损失。当同一分组只有一个小余组时，外部读者可以算出：

```text
小余组损失和 = 全体井数×全体平均损失 − 已报各组(井数×平均损失)
小余组井数   = 全体井数 − 已报各组井数
```

A使用10口合成井、9+1回退分组，执行当前`budget`，精确恢复了被隐藏的单井损失。该程序能力已确认；没有读取或证明任何真实井已被泄露。B本轮真实预算尚未生成，当前公开准备包的扫描通过与该未来发布缺陷是两回事。

最小保守修复：某个分组维度存在少于5井的组时，整个维度的组级数值不发布；或者实现有验证的互补抑制/合并。独立补丁选择前者，保留所有组均≥5的维度。这样不改变分组定义、训练矩阵或选模分数。

编号：**A035-R14-02 / P1 / 未关闭**。阻断当前预算发布路径及包含该路径的增量签署。
