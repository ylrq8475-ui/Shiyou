账户B执行与交付。Python 3.13.7、pandas 2.3.3、PyYAML 6.0.3；不需要模型依赖，不加载权重。

在具有本机赛事数据读取授权的环境使用新输出目录；参数均从命令行明确提供，脚本没有原机器绝对路径：

```text
python -m unittest -v test_evidence.py
python compute_evidence.py --archive <原始赛事ZIP> --manifest <冻结原始逐文件清单JSON> --config <冻结私有配置YAML> --dictionary FIELD_DICTIONARY_PUBLIC.json --safe-source <原a2b013_safe.py> --multistep-source <原multistep.py> --output <不存在的新目录>
```

脚本逐字节核对100项原清单，不解压；只解析88份训练井史的4个必要字段，以及已授权共享层位/方案表。训练RCYL只用于确认既有81口完整目标队列，不用于新拟合或新评分。使用原始eligible事件值，仅在内存。队列标签键与顺序哈希应与A2B-028 B0分数前锁一致。

测试标识仅由清单文件名和训练文件名绑定规则在内存生成；不解析测试井史和测试标签。E1测试字段覆盖不决定方案条件或选择白名单。

C2要求所有方案完工日期可解析且归一化后的完整日期唯一；不会将同月多日期视为唯一。C3/C4独立计数在多事件井上使用当前最后事件段，C1单独要求只有一段；无可判日期记不满足。最终N_Q2_all取四条件交集。另报累计交集，不能把独立失败数相加。

完工日期不是方案编制时间；当前共享字节不是历史版本证明。复测能核对计数、身份与公开引文，不自动解决Q1/Q2可得性。所有产物仅匿名聚合，切勿新增逐井保存。图像/PDF按SOURCE_RECEIPT从官方来源本地阅读，不将原件上传。
