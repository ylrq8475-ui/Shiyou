## 3. 为什么CV略升而平台略降

最佳候选重复均值提高0.076543，五次配对增量为`+0.057118、+0.188542、+0.113375、+0.158772、−0.135093`；原固定五折增量为`−0.046699、−0.338861、−0.500772、+0.646019、+0.951500`，只有2折改善。重复前两月损失折算为分数改善0.079344，3—12月合计抵消约0.002801。这是很小且不均匀的改进，不是稳定的大幅增益。

这74个配置在同81口训练井、同五组重复切分上被比较和筛选；尺度/特征选择、参数选择、融合成员选择都使用了这些分数。每个模型的折内拟合守住标签隔离，仍不等于“选出的冠军”拥有独立、无偏的泛化评估。重复切分并未增加独立井的数量，也没有把已用于筛选的分数变成独立确认。配对种子标准误约0.057371只作描述，不据此构造独立重复置信区间或判定统计显著。

对同一隐藏评估集，降分表示新预测的加权相对误差确实更高，不能把它说成平台随机抖动。可以解释的是：训练验证中的微小平均收益没有转移到这批隐藏井。选择乐观性、井间异质性、全量拟合后的变化均是可检验假设；现有材料不能确定各自占比，也没有证据直接判定数据分布漂移、过拟合已被证明、锚点再次错位或指标实现错误。

“从86.2003降到79附近”与“79.4717降到79.3643”要分开。后一差异主要对应本批树参数候选，前一差异跨越不同历史版本，尚缺旧平台包到源码/配置/完整复现的身份链。当前新加的路线不能解释历史约6.7分落差。

有四个值得改进的设计点：

1. **多输出的叶节点参数不是同强度对照。** `models035.py::fit_single`对单输出使用972个月行，对多输出取每井首行并构造81×12目标；外层训练约64—65井。同样leaf10，前者约束月行数，后者约束井数，强度不同。当前同数值参数的32组配对，多输出只有10组更好，平均低0.146832；可描述该配置网格效果，不能当作只改变“输出形式”的干净因果实验。源码没有传入官方早月权重；多输出跨期共享分裂可能与前两月优先目标冲突，这是待验证机制，不是已证明的降分原因。

2. **融合选的是近似同一模型。** `FUSION_MEMBERS_BEFORE_SCORES.json`明确两成员仅400/800树不同，都是leaf10、max_features1.0、last_legal、base325。代码权重在训练侧内层OOF确定，未发现外层标签直接调权；但成员先由全局重复CV选出，完整选模流程仍有选择乐观性。当前资料没有残差相关/互补改善聚合表，不应直接宣称相关系数很高或已量化互补不足。实际融合不及最佳单模是已复算事实。

3. **多样性筛选与官方目标不对齐，且拒绝证据未保存。** `run_search.py`对12个月OOF对称预测差直接取均值；不使用2^-t。晚月差异可能主导筛选，未必改善前两月错误。纯合成案例验证这种排序反转可以发生，并未证明本次真的发生。本批`CANDIDATE_SELECTION.json`只保存入选的1项，其差异为null；其余被拒候选的差异值没有保留，逐行OOF也没有持久化，A无法复算“为何只有1个”。这是P2证据缺口，不是已发现错选或违规。以后保留候选级拒绝原因、全期/前两月加权差异和误差互补聚合，不能为补此证据追重训整批。

4. **早期筛选会漏掉表示与模型的交互。** 只在ET400/leaf6/.75上筛掉R和其他尺度，再扩大树网格，节省计算但不能排除R×不同学习器的有效组合。当前应优先一个有机制依据的交叉对照，不应把“没穷尽”当作继续全组合搜索的充分理由。
