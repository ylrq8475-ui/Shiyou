建议保留双方最差绝对折分作为报告项，条件确认增加明确的 `min_f(R1_f - B0_f) >= -1.00` 配对风险门槛，并以唯一含义命名。固定回放列出该值用于观察，不将已看过的固定分数包装为新确认。上述门槛必须在所有后续新分数产生前锁定，失败不调整。

### 3. 数组形状通过不等于真实井月对齐

真实执行入口须在转换成裸数组前验证两臂的井键、月份/顺序、样本队列、raw 状态、共同特征与信息边界身份。新增最小故障注入：仅置换 C1 井顺序；仅置换 C1 月顺序；置换 raw 状态；同形状但一臂来源于不同折。都须在评分前报错，并阻止额外确认、全量拟合和保存。正常分支逐值核对正尺度井等于 B0、回退井等于 C1。

### 4. 预算：模型与预处理的成功/进入计数不能混用

B 提案计划最多 70 次 CV、2 次全量成功模型拟合，最多 2 次故障重试，总进入上限 74，计算正确。但“预处理最多 72 次成功”在模型失败重试情形下不一定成立：预处理已成功、随后模型失败时，重试会增加一次成功预处理。

这不是扩大模型预算，只是按真实调用路径明确预处理计数。
