# 路线B预注册定稿：精确零月识别与固定B0回归分支

账户B执行与交付。Claude负责方案与指令；Codex只独立审核；本文件由B补全实现口径和拟合预算，不构成B-2训练授权。本轮只写文件和隐私补扫。

## 1. 来源、假设与本批唯一变化

原机制来源：固定提交3256382fb56efecf37f54b4ce3bd4287ffe1f71c的RESEARCH_DIRECTION_REVIEW.md“路线B”，即B0加零判别，非零输出分支逐值沿用B0。

用户转交的Claude草案假设原文：“把停产月（RCYL 为 0 或接近 0）单独处理，即先用分类器判断是否停产，再用回归器预测非停产月，可以回收 D1 上界 2.6479 分中的一部分。”

本批操作定义严格采用原路线B和D1的“精确0”。“接近0”尚无给定界限且D1没有计算它的预算，因此不添加小正值阈值。回归器用于没有被零判别器判为停产的月份，仍按原B0在全部合法训练井月拟合；不改为只在真实非零标签子集重训回归器。否则会同时改变正值回归学习机制，超出原B0加零判别的单因素。

候选P：对每个验证井月，p_P=0若分类分数q0>τ；否则p_P=p_B0。不能利用验证真值阻止误停；真实正值月被误判的代价必须计入官方指标。不存在其他候选、路由、融合或超参数搜索。

阶段B-1仅预注册；阶段B-2需要另行批准，且启动前必须由Codex明确关闭第11项。B的24/24补扫通过不代替Codex签署。

## 4. 固定外层五折与内层τ选择

外层沿用原固定GroupKFold(5)，按WELL_ID隔离；原行顺序、全部模型种子20260916不变。固定切分摘要beadb191d075afdd138d6463f0b3a0e03999a76e07641f56ea24ec77e5e4d5f8。原参考OOF73.71410733861434作为身份核对值，最终候选增益须用本轮同环境、同切分的B0 OOF相减；不能用它替代缺失的折外预测。旧聚合没有内存OOF可复用，本计划登记新B0生成，不重跑已完成其他实验。

对每个外层训练井集，使用GroupKFold(3)，shuffle=False，按WELL_ID隔离。每个内层折仅拟合原B0回归器及其预处理器，预测该内层验证井；不拟合内层分类器，不搜索分类阈值。外层验证井从始至终不参与这个步骤。

严格沿用3256382中路线B的公式：τ=(1−ℓ+)/(2−ℓ+)。ℓ+仅在内层验证折按真实正值目标和B0预测估计。对每口有至少一个正值目标的内层验证井，先计算sum(2^-t×单月损失×I(y>0))/sum(2^-t×I(y>0))，单月损失为abs(p−y)/(abs(p)+abs(y)+1e-6)；再对该折这些井等权平均，最后对三个内层折的标量均值等权平均，得到该外层折的ℓ+。仅此条件期望估计使用正值条件分母，最终官方指标绝不归一化时间权重。零目标不用于估计ℓ+，仍完整保留在B0训练与最终官方评价中。

每个外层折据公式直接得到一个τ。没有阈值网格、没有按分数取最大阈值、没有拼接OOF后选阈值。禁止使用整体OOF、外层OOF、外层标签、测试数据或平台成绩选τ。若任一内层折无法估计正值损失，或ℓ+非有限/不在[0,1]，结构检查失败，在外层评分前停止；不临时更换估计方法。

随后用全部外层训练井拟合共享预处理器、B0回归器及零分类器，使用冻结τ预测外层验证井。q0>τ时置零，q0==τ时保留同折B0预测，以保持原公式的严格不等号。B0本来已为0时分支输出仍为0，不影响一致性。五个外层折全部按计划执行，模型随机种子20260916；内层和外层顺序执行，只有当前ExtraTrees对象使用n_jobs=-1，禁止同时并行多折。

该公式来自零/正值分支损失近似，原推导把零与正值误置零损失近似为1；在保留epsilon=1e-6的真实指标中不保证严格最优。树概率不做校准，是否有效仅由B-2受控实验判断。不得把公式阈值称为官方最优阈值，也不以OOF微调来修补该近似。
