# Round 3 experiment scripts (2026-09-27)

These are the exploratory scripts behind `docs/round3_handoff.md`. They print aggregate statistics only (no well IDs, rows or raw category values).

Layout they assume (adjust the paths at the top of `common.py` / `exp.py` if different):
- repository checkout at `~/work/repo` with the private runtime config already generated by
  `scripts/analyze_anchor_candidates.py` + `scripts/prepare_private_runtime_config.py --safe-plus-layer` (candidate codes CSLB_012, CSLB_032);
- official data at `~/mnt/data` (`train_data/`, `test_data/`, layer and plan CSVs at the root);
- scripts copied to `~/work/` and run from there, e.g. `python3 run_base.py`-style entry points are the `if __name__ == "__main__"` blocks.

Main entry points
| script | purpose |
|---|---|
| `a2b.py` | A2B-013 / v7 panel rebuild and repeated-CV scores (`python3 a2b.py A2B 0 0 0 5`, `python3 a2b.py V7 1 1 0 5`) |
| `ts.py` | global sliding-window time-series model (`python3 ts.py 1 all hgb 1 2`) |
| `leanfix.py` | lean level-correction model blended with A2B-013 (`python3 leanfix.py 1 et 5`) |
| `aug.py` | historical-event augmentation |
| `resid.py`, `edge1.py`, `edge2.py`, `sim.py` | residual / regime / distribution-shift analysis |
| `clean.py` | data-quality checks |
| `cond.py`, `noise.py` | 10-well platform-noise bootstrap |
| `scoreboard.py` | unified local scores for all submitted models |
| `pack.py` | whitelist code-package builder |

The production versions of the submitted candidates live in `src/oil_uplift/ts_blend.py` and `reproduce_candidate.py`.
